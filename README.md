# 链页数据库系统（ChainPage DB）

本系统是“大型平台软件设计实习”项目，目标是从 SQL 语言出发，逐步实现一个可执行、可持久化的小型数据库系统。

## 项目组成

1. SQL 编译器：将 SQL 文本转换为 Token、AST、语义检查结果和逻辑执行计划。
2. 页式存储系统：负责页的分配、释放、读写、缓存和持久化。
3. 小型数据库系统：调用 SQL 编译器生成的执行计划，并通过页式存储系统完成建表、插入、查询和删除。

整体数据流为：

```text
SQL 文本 → SQL 编译器 → 逻辑执行计划 → 数据库执行引擎 → 页式存储系统 → 磁盘数据
```

## 目录结构

```text
sql-compiler/         SQL 编译器及其规约
page-storage-system/  页式存储系统及其规约
database-engine/      数据库系统及其规约
docs/                 项目指导书和任务材料
module-interfaces.md  三部分之间的跨模块接口规约
```

## 开发顺序

1. 完成 SQL 编译器
2. 完成页式存储系统
3. 完成数据库系统集成

各模块的输入输出格式、错误格式和调用关系以对应目录中的规约文档及根目录的跨模块接口规约为准。
